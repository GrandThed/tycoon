# Combat sound audition

Listen to each option (the file names are links: Ctrl+click in VS Code, or open the folder in Explorer),
then tick **one** box per sound. Tick **None** if all three are bad; that sound stays silent for now.
Anything goes in *Notes*, e.g. "too loud", "wrong mood", "want something more metallic".
When you are done, save the file and tell Claude "sounds done".

Files live in `assets/audition/<sound>/`. Nothing is uploaded until this form is filled in.
