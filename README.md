# Era City Tycoon

A mobile-first Roblox plot tycoon: claim a plot, grow a medieval village into a boomtown, a
metropolis, and finally an orbital colony. Completing an era resets your plot but grants
permanent **Legacy** — era progression is the prestige loop. Progress persists across sessions
(ProfileStore), including offline earnings on rejoin. Optional, restrained monetization (game
passes, time-priced cash packs, Premium) stays fully hidden until game-pass/product ids are
created and pasted into config — see `docs/MANUAL_STEPS.md` M4. From C0 the experience has a
**second place, "Expeditions"** (co-op wave defense): the hub's Armory buys weapons with era
materials, and Depart teleports the same profile into `build/combat.rbxl`. Built with Luau and
Rojo. Full design in [`docs/SPEC.md`](docs/SPEC.md).

## Quickstart

The pinned toolchain lives at `~/.rokit/bin` and is **not** on PATH by default — set it first:

```powershell
# PowerShell
$env:PATH = "$HOME\.rokit\bin;$env:PATH"
```
```bash
# Git Bash
export PATH="$HOME/.rokit/bin:$PATH"
```

```powershell
# 1. Restore the pinned toolchain (rojo, wally, stylua, selene, luau-lsp)
rokit install

# 2. Install Luau dependencies into Packages/ and ServerPackages/
wally install

# 3a. One-shot build -- the hub place
rojo build -o build/test.rbxl

# 3b. One-shot build -- the Expeditions (combat) place, from C0 onward
rojo build combat.project.json -o build/combat.rbxl

# 3c. OR live-sync while Studio is open (Rojo plugin → Connect)
rojo serve
```

Python is invoked as **`py`** on this project (not `python`/`python3`, which don't resolve on
Windows without the Store stub getting in the way):

```powershell
py tools/sim_economy.py --check
py tools/sim_combat.py --check        # Armory unlock ladder and run pacing (from C0)
py tools/gen_asset_manifest.py        # regenerates docs/ASSET_MANIFEST.md from the era configs
py tools/gen_asset_manifest.py --check
```

Then follow [`docs/PLAYTEST.md`](docs/PLAYTEST.md) for what to check in Studio, and
[`docs/MANUAL_STEPS.md`](docs/MANUAL_STEPS.md) for anything that has to happen in Studio or the
Creator Hub (plugin install, mesh import, audio upload, game passes/products).

Line endings are LF everywhere (`.gitattributes` enforces it) — `stylua --check` fails on CRLF.

                             testfit/ + assets/ (from M7 onward) -- the growing-building pipeline
                             (both gain --props for city-dressing props, M9), streetplan.py (M9

## Asset pipeline (from M7 onward)

Village's buildings are Kenney-kit meshes that grow through five stages (buy, then base
milestones 10/25/50/100) — no hand-importing in Studio. Each building starts as a blueprint
(`tools/testfit/blueprints/<Era>/<ModelName>.json`, previewed with
`py tools/testfit/testfit.py`), then runs through a scripted pipeline: Blender merges each stage
into one mesh (`tools/assets/merge_stages.py`), `tools/assets/upload_models.py` uploads via Open
Cloud, one Studio-only step (`tools/assets/harvest.py`) reads back the mesh/texture ids Roblox
assigned, and `tools/assets/gen_templates.py` writes the committed `.rbxmx` templates under
`templates/`. `src/shared/Config/Assets.json` and `templates/` are both generated — never edit
them by hand. Full step-by-step: `docs/MANUAL_STEPS.md` M7. Other eras follow the same pipeline
in later milestones.
